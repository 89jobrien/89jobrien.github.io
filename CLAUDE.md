# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this
repository.

## What this repo is

Static GitHub Pages site at `89jobrien.github.io`. All HTML is **generated output** — do not
edit it by hand. The source of truth is the `bazaar` repo (`~/dev/bazaar`), which contains the
generator (`bazaar-gen`) that produces `index.html` and `projects/*/index.html`.

## Sync workflow

A daily GitHub Actions workflow (`.github/workflows/sync.yml`) fetches the latest `index.html`
from `bazaar`'s `main` branch and commits it here if changed. Manual trigger: `workflow_dispatch`
via `gh workflow run sync`.

To force a local sync from bazaar's published output:

```bash
curl -fsSL https://raw.githubusercontent.com/89jobrien/bazaar/main/index.html -o index.html
```

## Making changes

- **To change site content or layout**: edit the generator in `~/dev/bazaar`, then re-run it and
  push the output to `bazaar`. The sync workflow will pick it up within 24h (or trigger manually).
- **To change the sync schedule or workflow**: edit `.github/workflows/sync.yml` using a Bash
  heredoc (the Edit tool is blocked for workflow files).
- **To add a project page**: project pages under `projects/*/index.html` are also generated by
  bazaar. Do not create them manually.

## Data

`data.json` is the raw data blob used by the generator — it contains GitHub API responses for all
showcased repos. It is also regenerated by bazaar.

## Deployment

Pushes to `main` deploy automatically via GitHub Pages. No build step.
